# Garage Therapy

Garage Therapy offers same-day residential garage cleanouts. The crew sorts items with the homeowner, hauls away unwanted items, deep cleans the garage, and can make an on-the-spot cash offer for eligible valuables. The advertised base price is **$699 for a standard one- or two-car garage**.

[Preview the landing page](https://raw.githack.com/bpoplstein1/garage-therapy/13f2c0793f471ef0090b605f176a1cd25af607cc/index.html)

## Website and quote calculator

The site lives in `index.html`, which contains the HTML, CSS, illustrations, and JavaScript. Open it directly in a browser to preview changes. No installation or build step is required.

The five-step calculator asks about garage size, how full it is, optional services, timing, and contact details. It displays an itemized estimate in the browser. The current submit handler logs the lead to the browser console. It does not send a quote request to the business.

## Editing the site

- **Pricing:** Update the displayed prices and the calculator rules together. Test a standard garage and a job with add-ons, and compare the itemized lines with the total.
- **Service area and contact details:** Replace `[Your Metro Area]` and the sample phone number in the footer. Verify the email address and domain before publishing.
- **Lead delivery:** Connect the submit handler to the intended inbox or CRM. Test a submission from the published page and confirm it arrives before directing customers to the form.
- **Customer-facing claims:** Confirm the testimonials, licensing, and insurance language before launch.
